FakeFido is a small command-line project for exploring FIDO2 and WebAuthn with a virtual USB device.

Get started ↓Built on Virtual FIDO ↗
terminal

$ fakefido start

virtual device · local machine

!

Please read before using

This is not real WebAuthn security.

FakeFido is software, not a hardware authenticator. Credentials (often called passkeys) are stored in a local JSON vault file. There is no secure hardware protecting the keys, device-bound storage, or hardware-backed user verification.

That differs from passkeys protected by Apple or Android devices, and physical security keys such as YubiKeys. Do not use FakeFido to protect real accounts or sensitive data.

Under the hood

A demo built on
Virtual FIDO.

FakeFido wraps BulwarkID’s Virtual FIDO repository, which implements a virtual FIDO2/U2F USB device. This project connects that library to a simple command-line demo and local credential vault.

It’s a place to learn, inspect the code, and experiment with test accounts. A virtual device cannot provide the physical isolation or assurances of an actual authenticator.

Linux · systemd

Run it locally.

The installer picks an amd64 or arm64 build, installs USB/IP, then enables FakeFido as a system service.

Set FAKEFIDO_R2_PUBLIC_URL to the public base URL configured for the release bucket.

Install · requires root

export FAKEFIDO_R2_PUBLIC_URL="https://your-download-domain"
curl -fsSL "$FAKEFIDO_R2_PUBLIC_URL/latest/install.sh" | sudo env FAKEFIDO_R2_PUBLIC_URL="$FAKEFIDO_R2_PUBLIC_URL" sh

Service

sudo systemctl status fakefido
sudo journalctl -u fakefido -f

A random vault passphrase is created in /etc/fakefido/fakefido.env. Back it up securely. The vault is at /var/lib/fakefido/vault.json.

Curious about the implementation? The code is open. Read the warning, then experiment with test accounts.
